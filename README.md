# 🎮 Hangman Game – Python

A simple text-based Hangman game developed using Python as part of the CodeAlpha internship task.

The player guesses a randomly selected word one letter at a time, with a maximum of 6 incorrect guesses allowed.

## 🎯 Project Objective

To create a console-based word guessing game using basic Python programming concepts.

## ✨ Features

- Random selection from 5 predefined words
- Word category display
- Maximum 6 incorrect guesses
- Input validation for single alphabetic characters
- Prevents duplicate guesses
- Reveals correctly guessed letters
- Win and lose messages

## 🛠️ Technologies Used

- Python
- Random module
- While loop
- If-else statements
- Strings and lists

## 🚀 How to Run

1. Download `hangman.py` from this repository.
2. Open a terminal in the folder containing the file.
3. Run the following command:

   ```bash
   python hangman.py
   ```

No external libraries or additional setup required.

## 🎮 How to Play

1. Run the Python program.
2. Check the randomly selected word category.
3. Enter one letter at a time to guess the word.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word before reaching 6 incorrect guesses to win!

## 📚 Learning Outcomes

- Random selection using the `random` module
- Loops and conditional statements
- Working with strings and lists
- User input and validation
- Basic game logic
